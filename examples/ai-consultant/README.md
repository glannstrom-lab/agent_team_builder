# Exempel-output: ai-consultant

När du har byggt konsult-läget, checka in output från tre fiktiva kunduppdrag
här. Ingen riktig kunddata — använd påhittade företag eller anonymiserade
versioner av faktiska uppdrag.

Rekommenderade test-case (en per mognadsnivå):
- `beginner-accountant/` — Liten bokföringsbyrå, AI-nybörjare
- `intermediate-agency/` — Marknadsbyrå som använder ChatGPT
- `advanced-studio/` — Designstudio som börjat bygga själva

Samma kvalitetstest som team-builder: output ska vara meningsfullt olika
mellan exemplen. Om ett nybörjarexempel ser ut som ett byggarexempel är
något fel i mognadsjusteringen.

## Integritet

Använd aldrig riktig kunddata i exempel. Anonymisera eller hitta på.
