# Exempel-output: team-builder

När du har byggt team-builder-läget, checka in output från tre testkörningar
här. De fungerar som regression-tests och som dokumentation för nya
användare.

Rekommenderade test-case:
- `bonusloots/` — Solo affiliate-sajt, intervju-läge
- `coachonline/` — Solo coaching-sajt, intervju-läge
- `ikea/` — Enterprise, externt företag-läge

Om en ny version av verktyget ger märkbart annorlunda output för dessa
exempel — fundera på om ändringen är en förbättring eller en regression
innan du committar.
