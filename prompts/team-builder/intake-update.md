# Uppdaterings-intake (team-builder, läge C)

Läser befintliga agenter i .claude/agents/, frågar vad som förändrats,
föreslår diff.

**Status:** Ej skriven.

## Absolut regel

Default är torrkörning. Inget skrivs över tyst. Varje ändring kräver
explicit godkännande. Om en agent ska ändras — visa diffen först.
