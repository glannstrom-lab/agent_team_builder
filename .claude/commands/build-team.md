# /build-team

Startar team-builder-läget. Se docs/team-builder.md.

**Status:** Ej skriven.

## Användning

- `/build-team` — intervju-läge (A)
- `/build-team [företagsnamn]` — externt företag (B)

Om .claude/agents/ redan finns i målprojektet — föreslå /update-team istället.
