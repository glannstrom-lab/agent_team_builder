# Agent-grundskelett

Grundmallen som alla genererade agenter byggs på. Team-builder-läget
använder den direkt; ai-consultant-läget lägger till pedagogiska sektioner
i agent-pedagogical.md.

**Status:** Ej skriven.

```
<!-- Varför denna agent finns: [motivering från research/intake] -->

[En mening]

- [verb]
- [verb]

## Triggas av
[typ av uppgift]

## Rör inte
[avgränsning]

## Samverkan
[Hur den pratar med VD och VD-assistent]
```
