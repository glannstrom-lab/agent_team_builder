# Mötesmall: Projektgranskning

Bred svephandling över hela projektet eller ett större område.

## Syfte

Få en samlad bild av var projektet befinner sig, sett från flera
agenters perspektiv. Slutar alltid i en rangordnad lista — inte
en ostrukturerad hög av observationer.

## Deltagare

VD-assistenten väljer vilka agenter som deltar baserat på vad
granskningen gäller. Inte alla — bara de som har relevant perspektiv.

- **VD-assistent:** Leder, sammanfattar, producerar output
- **VD:** Deltar om granskningen berör riktning eller prioritering
- **Specialister:** De vars domäner berörs

## Körning

### 1. Ram (VD-assistenten)

Innan någon agent får ordet:

> **Granskning av:** [vad som granskas]
> **Mål:** En rangordnad lista av de viktigaste fynden
> **Deltagare:** [lista]
> **Tidsram:** [vad som granskats sedan senast, eller "allt"]

Visa ramen för användaren. Om de vill justera — justera.

### 2. Rapportering (en agent i taget)

Varje deltagande agent svarar på:

1. **Vad ser jag från min vinkel?** Konkret observation, inte
   abstrakt bedömning.
2. **Vad oroar mig?** Risk, flaskhals, något som glider.
3. **Vad fungerar?** Något som är värt att lyfta positivt.

Max 3–5 meningar per agent. VD-assistenten avbryter om det blir
längre eller börjar överlappa med en annan agents perspektiv.

### 3. Rangordning (VD-assistenten)

Sammanfatta alla rapporter och producera output-formatet.

## Output-format

```markdown
# Projektgranskning: [datum]

## De tre viktigaste fynden

### 1. [Fynd]
**Rapporterat av:** [agent]
**Påverkan:** [vad som händer om inget görs]
**Rekommendation:** [en konkret handling]

### 2. [Fynd]
...

### 3. [Fynd]
...

## Övriga observationer (sorterade efter vikt)

- [Observation] — [agent]
- [Observation] — [agent]

## Vad som fungerar bra

- [Positivt fynd] — [agent]
```

## Risker att bevaka

- **Rörig output:** Om rangordningen inte kan göras — ställ följdfrågor
  till agenterna tills det blir tydligt vad som är viktigast.
- **Alla säger samma sak:** Bra signal att det är ett verkligt problem.
  Slå ihop till ett fynd och notera att flera agenter oberoende lyfte det.
- **En agent dominerar:** VD-assistenten ska fördela ordet jämnt.
